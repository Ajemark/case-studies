# Snipey App — Case Study

> **AI-Powered Solana Trading Bot with 97% Code Reduction**
>
> 🔗 [Live Demo](https://snipey.vip)

## Overview

**Snipey App** is an AI-powered Solana trading bot that achieved a 97% code reduction (50K LOC Rust → 3.5K Python). Features Playwright-based X/Twitter scraping, social sentiment analysis, and Jupiter DEX integration.

## Tech Stack

- Python, FastAPI, TypeScript, Playwright, Jupiter DEX

## Key Features

- 97% code reduction
- X/Twitter social monitor with Playwright
- Sub-5-second token analysis
- Jupiter DEX integration
- PNL tracking
