# Ascension Protocol — Case Study

> **Cultivation Metaverse Powered by Real-World Habits**
>
> 🔗 [GitHub](https://github.com/Ajemark/ascensiondao)

## Overview

**Ascension Protocol** is a cultivation metaverse where real-world habits fuel progression through realms. Body tempering via exercise, mental refinement via learning, spirit condensation via mindfulness.

## Tech Stack

- Next.js, TypeScript, Web3

## Key Features

- Habit RPG mechanics
- Spirit beast system
- Territory ownership
- PvP & sect warfare
- 9 cultivation realms
