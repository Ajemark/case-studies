# Badger Games — Case Study

> **Multi-Game Brain Training Platform with RPG Progression**
>
> 🔗 [Live Demo](https://badger-bot.vercel.app) · [GitHub](https://github.com/Ajemark/badger_buy_bot)

## Overview

**Badger Games** is a multi-game brain training platform featuring Wordle, Sliding Puzzle, and Quiz games with RPG progression, XP/coin economy, and AI-powered dynamic quiz generation.

## Tech Stack

- Next.js, TypeScript, Tailwind CSS, Gemini AI, TON Blockchain

## Key Features

- 3 brain-training games
- RPG progression system
- XP/coin economy with daily streaks
- AI-generated quizzes via Gemini
- TON blockchain integration
