# OurConnected Next — Case Study

> **Enterprise-Grade Platform with RBAC, Encrypted Document Vaults & AI Chatbot**
>
> 🔒 *Source code is private under client NDA.*

## Overview

**OurConnected Next** is an enterprise-grade web platform built for client-project manager collaboration.

**Role:** Lead Full-Stack Developer

## Architecture

```
Next.js Frontend  ←→  Supabase Backend  ←→  PostgreSQL  ←→  AI Chatbot (Gemini)
```

## Tech Stack

- **Frontend:** Next.js 15, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Supabase (Auth + Storage + Edge Functions)
- **AI:** Google Gemini API, LangChain
- **Security:** Row-Level Security (RLS), AES-256 encryption

## Key Features

- Granular RBAC with 5 role tiers
- Encrypted document vault with key rotation
- Interactive Gantt chart project tracking
- AI-powered 24/7 customer support chatbot
- Real-time sync via Supabase subscriptions

## Metrics

- ~77 commits across frontend and backend
- 5 role tiers with 40+ permission combinations
- 99.9% uptime via Supabase managed infrastructure
