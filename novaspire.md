# NovaSpire — Case Study

> **Fast-Execution Solana Telegram Trading Bot**
>
> 🔗 [GitHub](https://github.com/nearlabdotfun/novaspire)

## Overview

**NovaSpire** is a fast-execution Telegram trading bot for Solana with auto-buy/sell via Raydium SDK and Jupiter API, PNL card generation, and secure wallet management.

## Tech Stack

- TypeScript, Raydium, Jupiter, JITO

## Key Features

- Auto-buy/sell
- PNL card generation
- Wallet management
- Real-time execution

## Metrics

- Solana ecosystem
