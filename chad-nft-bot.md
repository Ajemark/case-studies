# Chad NFT Bot — Case Study

> **Base Blockchain NFT Monitoring Bot**
>
> 🔗 [GitHub](https://github.com/Ajemark/chadNFT)

## Overview

**Chad NFT Bot** is a Base blockchain NFT monitoring system tracking transfers, listings, and price changes via OpenSea API with Telegram notifications.

## Tech Stack

- Node.js, MongoDB, OpenSea API, Telegram Bot

## Key Features

- Real-time NFT tracking
- OpenSea API integration
- Telegram notifications
- Multi-group management
