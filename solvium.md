# Solvium — Case Study

> **First Puzzle Game on NEAR Blockchain with AI-Powered Quizzes**
>
> 🔗 [Live Demo](https://t.me/Solvium_bot) · [GitHub](https://github.com/Solvium/SolviumAI)

## Overview

**Solvium** is the first-ever puzzle game on the **NEAR Blockchain**, combining strategy, fun, and blockchain rewards. Features AI-powered quiz generation via Google Gemini / LangChain and multi-chain reward distribution.

## Tech Stack

- Next.js, Python, LangChain, NEAR Protocol, Telegram Bot API

## Key Features

- First puzzle game on NEAR
- AI-generated quizzes via Gemini
- Multi-chain rewards (NEAR, Solana, TON)
- Telegram bot integration
