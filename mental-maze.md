# Mental Maze — Case Study

> **Decentralized Puzzle Game Protocol on Aurora (NEAR)**
>
> 🔒 *Source code is private under NDA.*

## Overview

**Mental Maze** is a decentralized puzzle game protocol built on **Aurora** (Ethereum-compatible blockchain on NEAR).

**Role:** Full-Stack & Web3 Developer

## Architecture

```
Next.js UI  ←→  Smart Contracts (Solidity)
       • Puzzle Generator
       • Merkle Proof Verifier
       • Reward Distributor
       • Anti-Cheat (Commit-Reveal)
```

## Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Contracts:** Solidity, Hardhat, OpenZeppelin
- **Blockchain:** Aurora (NEAR EVM-compatible)

## Key Features

- On-chain puzzle generation with infinite variations
- Merkle proof verification without revealing answers
- Commit-reveal anti-cheat mechanism
- Dynamic difficulty via oracle
- Multi-tier rewards scaling with difficulty
