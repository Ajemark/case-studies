# Artreus — Case Study

> **First Decentralized Omnichain dApp Store**
>
> 🔗 [GitHub](https://github.com/Ajemark/artreus-launchpad-1)

## Overview

**Artreus** is the first decentralized omnichain dApp store, enabling users to own, play, purchase, and earn across multiple blockchains.

## Tech Stack

- Next.js, Web3, Multi-chain

## Key Features

- Omnichain dApp distribution
- Cross-chain ownership
- Play-to-earn integration

## Metrics

- First of its kind
