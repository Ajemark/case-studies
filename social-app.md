# Social App — Case Study

## Overview

Full-stack social networking platform with real-time messaging, content feeds, and user engagement features. Built with a JavaScript-based architecture covering both backend and frontend.

**Category:** Full-Stack / Social  
**Role:** Full-Stack Developer  
**Status:** Live  
**Repository:** [social_app](https://github.com/Ajemark/social_app) (private)

## Challenge

Building a social platform requires handling real-time data, user-generated content, and scalable architecture while maintaining performance and security.

## Solution

Developed a complete social platform with:

- **Real-Time Messaging**: WebSocket-based chat system
- **Content Feeds**: Algorithmic and chronological feed options
- **User Engagement**: Likes, comments, shares, and notifications
- **User Profiles**: Customizable profiles with media uploads

## Architecture

```
React Frontend
    ↓
REST API (Node.js/Express)
    ↓
Database (MongoDB/PostgreSQL)
    ↓
WebSocket Server (Socket.io)
```

## Technologies

- **JavaScript** — Full-stack development
- **Node.js** — Backend runtime
- **React** — Frontend framework
- **Socket.io** — Real-time communication

## Key Features

1. **Real-Time Chat**: Instant messaging with read receipts
2. **Feed Algorithm**: Personalized content discovery
3. **Media Sharing**: Image and video upload support
4. **Push Notifications**: Cross-platform notification delivery
