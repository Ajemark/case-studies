# Blue Norva — Case Study

> **Blockchain-Based Staking Game on Distant Planet NorvaPrime**
>
> 🔒 *Source code is private under NDA.*

## Overview

**Blue Norva** is a blockchain-based staking game centered on mining resources from the distant planet NorvaPrime.

**Role:** Frontend Enhancer & Web3 Integrator

## Architecture

```
Next.js UI  ←→  Web3 Layer  ←→  Staking Contract + Resource Token (ERC-20)
```

## Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Contracts:** Solidity, Hardhat, OpenZeppelin
- **Web3:** WalletConnect, Ethers.js

## Key Features

- Time-locked staking with APY tiers
- Probabilistic resource extraction
- Peer-to-peer marketplace for mined resources
- Real-time leaderboard by total resources mined
