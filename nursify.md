# Nursify — Case Study

> **Healthcare Suite with 3 React Native Apps**
>
> 🔗 [GitHub](https://github.com/Ajemark/nursify)

## Overview

**Nursify** is a healthcare suite with three distinct React Native applications (Admin, Caregiver, User) using Expo and Firebase. Features real-time sync, document scanning, and secure medical data management.

## Tech Stack

- React Native, Expo, Firebase, Zustand

## Key Features

- 3-app suite (Admin, Caregiver, User)
- Real-time synchronization
- Document scanning
- Secure medical data
