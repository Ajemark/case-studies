# Magnitron — Case Study

> **Decentralized Voting Platform on TON Blockchain**
>
> 🔗 [Frontend](https://github.com/Ajemark/voting_app) · [Contracts](https://github.com/Ajemark/voting_app_contract)

## Overview

**Magnitron** is a decentralized voting platform on **TON blockchain** using Tact smart contracts, featuring TON Connect wallet integration and real-time on-chain result verification.

## Tech Stack

- Tact, TON Connect, MongoDB, TypeScript

## Key Features

- TON blockchain voting
- TON Connect wallet auth
- Real-time results
- On-chain verification
- Admin dashboard
