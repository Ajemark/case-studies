# AfroCarb — Case Study

## Overview

Climate tech platform for African carbon credit tracking and sustainability initiatives. Next.js dashboard for monitoring environmental impact and carbon offset programs across the African continent.

**Category:** Web2 / Climate Tech  
**Role:** Solo Developer  
**Status:** Live  
**Repository:** [afrocarb](https://github.com/Ajemark/afrocarb) (private)

## Challenge

Tracking carbon credits and sustainability metrics in Africa requires localized, accessible digital tools. Organizations need transparent systems to monitor environmental impact, manage carbon offset programs, and report on sustainability goals.

## Solution

Built a Next.js platform with:

- **Carbon Credit Tracking**: Monitor and verify carbon credit allocations and usage
- **Environmental Impact Monitoring**: Real-time dashboards for sustainability metrics
- **Sustainability Reporting**: Automated report generation for stakeholders
- **Dashboard Analytics**: Data visualization for carbon footprint analysis

## Architecture

```
Next.js Frontend

```
