# Moyo Pay — Case Study

> **Fintech Payments Platform**
>
> 🔗 [Live Demo](https://moyopay.io) · [GitHub](https://github.com/moyopay)

## Overview

**Moyo Pay** is a fintech payments platform with web app, landing page, backend API, and React Native mobile app. Features wallet services, on/off-ramp, and virtual card management.

## Tech Stack

- React Native, Fastify, Node.js, PostgreSQL

## Key Features

- Web and mobile apps
- Wallet services
- Virtual card management
- On/off-ramp integrations
