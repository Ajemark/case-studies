# Sastreria Manuel Fernandez — Case Study

> **Tailoring Business Website & E-Commerce Platform**
>
> 🔒 *Source code is private under client agreement with RyvoDigital.*

## Overview

**Sastreria Manuel Fernandez** is a premium tailoring business website and e-commerce platform built for a **RyvoDigital** client.

**Role:** Full-Stack Developer

## Architecture

```
Next.js UI  ←→  Backend API  ←→  PostgreSQL  ←→  Custom CMS
```

## Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Deploy:** Vercel

## Key Features

- Bespoke collection showcase with high-res image galleries
- Calendar-based appointment booking with email confirmations
- Client portal for order tracking and measurements history
- Multi-currency pricing (EUR / USD)
- SEO optimized with structured data

- ~130 commits
